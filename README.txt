DEBADRITA BIRTHDAY SURPRISE WEBSITE
====================================

This package includes:
- index.html: the complete birthday website
- photos/: the 10 photos you supplied, already included in the gallery

Preview:
1. Extract the ZIP.
2. Keep index.html and the photos folder together.
3. Double-click index.html to preview in your browser.

Publish with free GitHub Pages:
1. Sign in at https://github.com/
2. Create a NEW public repository named debadrita-birthday.
3. Upload index.html and the entire photos folder (all 10 JPGs) to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Choose branch "main" and folder "/ (root)", then Save.
7. Wait for GitHub Pages to publish and copy the URL it provides.
8. Open the URL in a private/incognito tab to confirm that the photos and letter appear, then send it to Debadrita.

Important:
- Upload the photos folder as well as index.html; otherwise the gallery images won't load.
- Music starts only when the visitor taps the music button.
- The page uses CSS-drawn cute bear/panda-inspired characters, not official Bubu & Dudu artwork.
- Since this is a public website, anyone with the link may be able to view the photos. Only publish photos you have permission to share.
